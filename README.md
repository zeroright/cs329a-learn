# CS329A 自学教学网站

纯静态站点：解压后可用浏览器打开 `index.html`。

推荐：

```bash
cd site
python3 -m http.server 8765
```

然后访问 http://127.0.0.1:8765/

- 官方作业与课表来源：https://cs329a.stanford.edu/
- 自编练习/自测/闪卡/Capstone 均标注「自编」
- Pyodide 代码运行需能访问 jsDelivr CDN（本地 server 模式）
