【官方 + 自编】HW1 · 测试时算力（AIME / Majority / BoN）

环境

  • 官方：见 homework/hw1/requirements.txt；通常需要 Python 3.10+、API Key（OpenAI 等）。
  • 免费/本地替代：小模型 + vLLM / HuggingFace transformers；或本站【自编】mock：repro/hw1/run_majority_bon.py（无 API）。
cd repro/hw1 && python3 run_majority_bon.py
# 期望：zero-shot < majority < best-of-N（规则验证器）准确率递增

子任务对照

子任务说明自编入口
Zero-shot单次采样基线mock_sample(..., n=1)
Majority voteN 次采样取众数majority_vote
Best-of-N验证器/RM 选最优best_of_n + rule verifier
RLEF 示意错答反馈再采样脚本末尾 rlef-mock

期望输出（自编）

zero-shot acc≈0.4 · majority@8≈0.6 · best-of-8≈1.0（玩具集，仅示意趋势）。

常见陷阱

  • 把 generative RM 当成 ground-truth：应用held-out 或程序验证交叉检查。
  • pass@k / majority 样本相关：报告时写清 N、温度、种子。
  • API 费用：先用 mock / 小模型验证管道再放大。

【外链官方 + 自编】HW2 · 验证 / HumanEval / pass@k
未再分发官方源码：仓库无 LICENSE。请自行 git clone https://github.com/stanford-cs329a/cs329a-homework2-fall2025-public.git

环境

  • 官方：按其 README（可能需 Docker 沙箱、API）。
  • 本地替代：本站 repro/hw2/run_pass_at_k.py 用 subprocess 临时目录执行（简易沙箱，非生产级隔离）。
cd repro/hw2 && python3 run_pass_at_k.py
# 期望：打印 n/c、pass@1/2/4（无偏估计）

子任务

子任务要点
沙箱执行超时、禁止依赖宿主机脏状态；官方常用容器
pass@k无偏公式 1 − C(n−c,k)/C(n,k)
LLM-as-judge注意位置偏差与自我偏好；与单测交叉

常见陷阱

  • 用有偏 pass@k（仅看至少一次成功）夸大结果。
  • 沙箱逃逸：不要在未隔离环境执行模型生成的任意代码（生产必须容器/gVisor）。
  • 测试泄漏进 prompt。
